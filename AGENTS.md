This is floof, a Flutter video client for e926 (and compatible booru hosts like e621).

- Keep the codebase grade-A; refactor rather than duplicating code.
- Every line must be covered by tests (`flutter test --coverage` at 100%).
- Run `flutter analyze` and `flutter test` before finishing any task.
- The recommendation engine is fully local; never send user behaviour off-device.
- User-facing strings go through the ARB files in lib/l10n, not hardcoded text.
